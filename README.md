# PHP 8.4 + MySQL 8 Starter for GadoHost

Clean **PHP 8.4 FastCGI + PDO MySQL 8** starter template designed for [GadoHost Web Hosting](https://gadohost.com/wordpress-hosting).

## What's Included

- Secure PDO MySQL 8 connection helper (`config/database.php`)
- Environment variable loader without heavy dependencies
- Ready-to-deploy `index.php` health dashboard verifying PHP 8.4 extensions and MySQL status

## Deploy in 15 Seconds

1. Create a **Custom PHP (8.1 – 8.4)** website inside [gadohost.com/web-hosting](https://gadohost.com/web-hosting).
2. Provision a **MySQL 8 Database** (includes 1-Click phpMyAdmin).
3. Upload these files via Web File Manager or isolated **SFTP / SSH**.
4. Copy `.env.example` to `.env` with your MySQL credentials and open your live HTTPS domain.
